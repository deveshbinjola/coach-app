The interview script

All 25 options in lib/assistant-interview.ts. One shared table feeds both /meet (public teaser) and /welcome (signed-in interview). Today 8 are written and all 8 are capability pitches. 17 are empty strings.

The rule for every line below

Name the pattern, then the help. The first sentence has to be true and useful to the coach even if they never buy anything. The assistant's capability comes second, quieter, or not at all. The moment "here's what I can do" leads the sentence, it stops being a reward and becomes an ad.

Council of mentors

Standing panel, run on this work before any code is written.

Karpathy · engineering rigor

Approves the shape. This is a data table, not logic. Option.reaction already exists and both surfaces already render it, so there is no new subsystem, no branching, and nothing new to test.

One real catch. An empty string cannot tell you whether a reaction is "not written yet" or "deliberately silent". After this pass those three tone blanks look identical to the seventeen accidental blanks they replaced, and the next contributor will helpfully fill them. Fix: type it as reaction: string | null where null means intentionally quiet and "" is a bug, then a one-line test asserts no option is ever "".

Naval · is the promise true, does it compound

True, and this is the rare change that makes the product more honest rather than more persuasive. Right now the interview extracts value and gives nothing back until the end. After this it gives something useful before asking for anything.

Does it compound? No. It is a fixed table, written once. It does not get better with use. What it does is raise the perceived worth of the thing that does compound, which is the coach's captured context. Cheap, durable, no maintenance. Fine to build, but do not mistake it for the moat.

Isenberg · funnel, positioning, distribution

Names the leak precisely. The free public teaser talks back. The signed-in product is silent. That is exactly backwards. The moment after signup is when a coach is deciding whether this was real, and right now it goes quiet on them.

Free distribution. The stage and niche lines are quotable on their own. "This is where most coaches stall. Not from a lack of leads. From dropping the ones they already have." is a post. The table is a content asset as well as a product surface, so write it to that bar.

Eyal · hook model plus the ethics gate

Hook: Trigger (the question) to Action (answer) to Variable Reward (the reaction, genuinely different each time and informative) to Investment (answering shapes what they get later). That is a clean loop and the reward is the honest kind. No streaks, counters or scarcity anywhere in it.

Gate, question one: does it materially improve the coach's business? The stage and niche lines are real advice they can act on today. Yes.
Gate, question two: would Sunny use this without knowing he built it? He would read the stage lines and recognise himself. Yes.

The standing risk: every one of these lines is one edit away from becoming a soft upsell. The eight that exist today already crossed that line once. If a future edit puts the capability first, the reward becomes an ad and the loop turns manipulative.

Stone · one click out

On the table: this is the same pattern as the page-header consolidation. One shared file feeds two surfaces and it drifted because nobody owned the whole. Filling the strings fixes today. The paved path is the rule that any new option ships with a reaction or an explicit null, enforced by the test above. Without that the table drifts again the next time someone adds a question.

The bigger assumption worth naming: is the interview the right place for coaching at all? It happens once. The daily brief happens every morning. If coaching is genuinely the product, the brief is where it lives and the interview is intake. These 22 lines are a taste, not the meal, and they are worth writing on that understanding rather than as the coaching feature itself.

Panel verdict

Build it. Cheap, honest, fixes a real leak. Two conditions carried forward from the panel: type the deliberate blanks as null with a test pinning it, and keep the capability sentence second or absent so the reward never becomes an ad.
