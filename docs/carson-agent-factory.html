The Factory Map local → cloud

From worktrees to a cloud factory

The migration path for coach-app. You don't leap to stage 3 — you earn it. Each rung removes one ceiling.

Stage 1 · Local

Worktrees on one machine

  • 1–2 agents, serial focus
  • Git worktrees to avoid collisions
  • Review at the desk only
  • Nightly self-heal loop runs local
Ceiling: your attention + one machine
Stage 2 · Hybrid

Cloud sessions, human gate

  • 3–5 concurrent cloud VMs
  • Each agent = isolated branch/PR
  • Phone review of PRs + unblocks
  • Prod keys stay in 1Password, pasted per-session
Ceiling: how fast you can review PRs
Stage 3 · Factory

Parent-child orchestration

  • Parent model plans + spins child sessions
  • 5–10 sub-tasks in parallel
  • Watchdog + E2E feed the loop
  • You approve merges, not tasks
Ceiling: trust in the eval + guardrails
