Turn On the Deposit Engine

The engine is built and merged-ready, but dormant. It does nothing until two pieces of config exist. This is the 15-minute checklist to make sessions start depositing into memory and the coaching-prep card come alive.

Surface · app.elevateaisystem.com PR · deveshbinjola/coach-app #28 Owner · Sunny Time · ~15 min

1 Set the model key in Cloudflare

The distiller calls a cheap model through OpenRouter. No key, no distill (it fails gracefully, nothing crashes, but no signals get saved).

  1. Get a key at openrouter.ai → Keys → Create key. Add a few dollars of credit.
  2. Cloudflare dashboard → Workers & Pages → the coach-app Pages project → Settings → Variables and Secrets.
  3. Add a secret (Production): name OPENROUTER_API_KEY, value = your key. Encrypt it.
  4. Redeploy (Deployments → Retry, or push any commit) so the new env is picked up.
Optional model override: defaults to google/gemini-2.5-flash. To try DeepSeek, add LLM_MODEL_DISTILL = deepseek/deepseek-chat. No code change.

2 Confirm the cron secret exists

The backstop sweep is guarded by a shared secret, same as your other cron routes.

  • In the same Cloudflare Variables screen, confirm CRON_SECRET is already set (your other crons use it). If not, add one (any long random string).

3 Schedule the sweep

On-demand distill runs the moment a session is saved. The sweep is the backstop that catches any that were missed or saved before this shipped. Hit it on your existing cron cadence (once or twice a day is plenty).

# GET, with the secret as ?key= or a Bearer header
https://app.elevateaisystem.com/api/cron/distill-signals?key=YOUR_CRON_SECRET
  • Add it wherever your other scheduled tasks live (the same place that triggers your morning brief / daily crons).
  • It distills up to 25 un-processed sessions per run and is idempotent, so running it often is safe.

4 Verify it works

Two-minute smoke test after the redeploy finishes.

  1. Sign in as a coach who has a client. Save a coaching session (a few real sentences of notes).
  2. On the session page you should see "Captured. Adding to [client]'s memory…" then "Remembered N things about [client]."
  3. Open that client. The Coaching prep card should show topics / commitments. Tap an item to see the source quote. Dismiss one and reload to confirm it stays gone.
If the banner just disappears and no signals show: the key is missing or wrong, or the redeploy did not pick it up. Re-check Step 1 and redeploy.

5 Make it trustworthy (before relying on it)

The distiller is only as good as its eval. Hand-label real sessions so you can measure quality, not vibes.

  1. Open eval/distill/golden.jsonl. Add ~10 real sessions: the raw notes plus the expected signals you would want surfaced. Your expected set defines the taxonomy.
  2. Run OPENROUTER_API_KEY=... npm run eval:distill.
  3. Pick 5, rate the model output yourself, and tune the judge until its scores track yours. An uncalibrated judge is theater.

Done when

  • OPENROUTER_API_KEY set in Cloudflare Pages, redeployed
  • CRON_SECRET confirmed, sweep scheduled
  • Smoke test passed: save → "Remembered N things" → prep card → tap-to-source → dismiss persists
  • ~10 golden sessions labeled, npm run eval:distill green, judge calibrated
