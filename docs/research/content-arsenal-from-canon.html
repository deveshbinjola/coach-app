Killing the approval bottleneck

Make Loki actually autonomous in 4 config moves.

You're right — agents that ping you for permission on every step aren't agents, they're slow assistants. The fix is operational, not philosophical. Four rules below. Apply once. The bottleneck dies.

RULE 1
Whitelist the low-risk surfaces

Blog posts, social drafts, Notion entries, calendar updates — auto-publish, never ask. In ~/.claude/settings.json, add the relevant permissions.allow entries (Bash to git push, Write to blog/*.html, MCP calls for Beehiiv draft creation). Approval only on send, not draft.

RULE 2
Reserve approval for irreversible ops only

Newsletter send (not draft). Client-facing emails. Anything billable. Anything published under your name to an audience > 1K. Everything else: ship and log. If it's wrong, you fix it post-hoc — that's cheaper than an approval wall.

RULE 3
Replace human gates with automated gates

Atlas's distinctive-asset check (palette/font/forbidden words) runs as a script, not a question. If output passes, ship. If it fails, regenerate. The QA is code, not a chat prompt.

RULE 4
Shift your QA from blocking to shaping

Your Thursday embodied pass doesn't gate this week's ship. It gates next week's brief. The content goes out either way. What you mark KEEP/CUT feeds the brand voice spec — so the next round drafts closer to your voice by default. After 6 weeks, drift is ~zero.
