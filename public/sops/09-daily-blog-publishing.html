Daily Blog Publishing

Owner: Loki (write), Atlas (QA + publish)
Cadence: Every weekday, 7am HST | Platform: The Signal on elevateaisystem.com/blog
Goal: 1 post per day, never remove posts, always add

Requirements

Post Requirements

Content

  • Audience: coaches & creators
  • Category: marketing strategy or tools (only these 3)
  • 2-3+ inline visual elements (charts, graphs, comparison tables, stat callouts, flowcharts)
  • Visuals built with HTML/CSS/SVG in brand colors — no external image dependencies

SEO

  • SEO meta tags (title, description)
  • JSON-LD BlogPosting schema
  • LinkedIn share metadata
  • Category badge

OG Image

  • 1200x630 PNG saved to Website/blog/images/{slug}-og.png
  • Wired into: og:image, twitter:image, JSON-LD BlogPosting.image
  • Brand template: navy #0A0F1C bg, green #00FF41 accent + left side bar, top-right radial glow
  • "THE SIGNAL . ELEVATEAI" eyebrow, category pill, white headline, stat callout

File Structure

  • Post HTML: Website/blog/{slug}.html
  • OG image: Website/blog/images/{slug}-og.png
  • Index: Website/blog.html (updated with new entry)
Topics

Topic Selection

Content Pillars (rotate through these)

  1. AI for coaches — tools, workflows, automation, prompt engineering
  2. Lead generation — funnels, content strategy, organic growth, SEO/AEO/GEO
  3. Business systems — pricing, offers, client management, scaling

Topic Sources

  • News from AI/coaching industry
  • Questions from coaches in DMs/Slack
  • Platform feature launches (write about the problem it solves, not the feature)
  • Competitor analysis
  • Keyword research (ELEVATE method: SEO + AEO + GEO + LLMO)

Hard Rules

  • Never remove existing posts — always add
  • Never publish duplicate topics (check existing blog index first)
  • No motivational fluff — every post must teach something concrete
  • Every post must have a clear "so what" for a coach reading it
Quality

QA Checklist (Atlas runs this)

  • Website/blog/{slug}.html exists and renders
  • Added to blog.html index with correct category, date, teaser
  • OG image exists at correct path
  • Meta tags present (title, description, og:image, twitter:image)
  • JSON-LD schema present and valid
  • Internal links injected (topic cluster "Keep Reading" links)
  • No broken links
  • Visuals render correctly (SVG/CSS charts)
  • Cloudflare Pages build passes
Recovery

Recovery

If a post doesn't generate by 7am:

  • Atlas flags it
  • Loki regenerates with explicit topic assignment
  • Target: published by noon same day

If QA finds issues:

  • Fix immediately — don't publish broken posts
  • If fix takes > 1 hour, skip the day (rare) and double-post tomorrow
